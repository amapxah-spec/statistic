# Эмнэлгийн өдөр тутмын мэдээ — Cloudflare Pages + D1

## Боломжууд
- Яаралтай тусламж, түргэн тусламж, тасаг нэгж гэсэн 3 төрлийн бүртгэл
- Нэвтрэлт: эхний админ тохируулах, дараагийн хэрэглэгчид админаар нэмэх
- Өдөр/төрөл/тасгаар шүүх, хайх, засварлах, устгах
- Хяналтын самбарын нийт дүн болон ангиллаар нэгтгэх
- CSV экспорт
- Cloudflare D1 өгөгдлийн сан; мэдээлэл браузерын localStorage-д хадгалагдахгүй

## Байршуулах заавар
1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git (эсвэл Wrangler ашиглана).
2. Энэ хавтсыг GitHub repository-д оруулж, Pages project үүсгэнэ.
3. Pages project → Settings → Functions → D1 database bindings хэсэгт `DB` нэрээр D1 өгөгдлийн сан холбоно.
4. `schema.sql`-ийг D1 дээр ажиллуулна:
   `npx wrangler d1 execute clinic-reports --remote --file=./schema.sql`
5. Pages project-ийн Environment variables / secrets хэсэгт `SETUP_KEY` нууц утга нэмнэ. Урт, санамсаргүй утга ашиглана.
6. `wrangler.toml` дахь database-ийн `database_id`-г үүсгэсэн D1 ID-гаар солино.
7. Deploy хийсний дараа аппын **Анхны админ тохируулах** хэсэгт `SETUP_KEY`, админы хэрэглэгчийн нэр, хүчтэй нууц үгээ оруулна. Setup key-г бусдад бүү өг.
8. Эхний админ үүссэний дараа setup дахин ажиллахгүй. Нууц үгээ аюулгүй хадгал.

## Орон нутгийн хөгжүүлэлт
- Node.js LTS суулгана.
- `npm install -g wrangler`
- `npx wrangler pages dev public --d1=DB:clinic-reports`
- API functions-ийг Pages project root дахь `functions/` хавтсаас ажиллуулна.

## Google Sheets-ээс мэдээлэл оруулах
Энэ хувилбар нь одоогийн Excel-ийн өргөн, олон мөртэй тайлангийн загварыг шууд хуулбарлахгүй; харин өдөр тутмын үзүүлэлтийг нэг мөрөөр оруулах, шүүх, нэгтгэхэд зориулсан цэвэр өгөгдлийн бүтэц ашиглана. Эхний өгөгдөл шилжүүлэхийн өмнө Excel-ийн давхардал, томьёо, огноо болон ангиллыг нягтална. Хуучин бүртгэлийг дараагийн хувилбарт импортын тусгай модуль нэмэн шилжүүлж болно.

## Аюулгүй ажиллагааны чухал тэмдэглэл
- HTTPS ашиглана.
- `SETUP_KEY` болон админы нууц үгийг source code-д бүү бич.
- D1 binding-ийн нэр яг `DB` байна.
- Клиникийн мэдээлэл, өвчтөнийг таних өгөгдөл оруулах бол байгууллагын мэдээллийн аюулгүй байдал, эрх зүйн шаардлагыг урьдчилан баталгаажуул. Энэ загвар өвчтөний нэр, регистр зэрэг таних мэдээлэл шаардахгүй.
- Нэвтрэлтийн session 12 цаг хүчинтэй; cookie HttpOnly, Secure, SameSite=Strict.
- Үйлдвэрлэлд тавихаас өмнө зөвшөөрөгдсөн хэрэглэгчид, нөөцлөлт, audit болон нөхөн сэргээх туршилтыг байгууллагын бодлогын дагуу хий.
